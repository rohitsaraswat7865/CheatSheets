Basic Selectors
Fundamental selectors for targeting elements by type, class, or ID
Selector Reference
Basic
*
Selects all elements (universal selector). Use sparingly.
div
Selects all <div> elements by tag name.
.className
Selects elements with class="className".
#myId
Selects the element with id="myId". Should be unique per page.
div.card
Selects <div> elements that also have class card.
.a.b.c
Selects elements that have all three classes simultaneously.
Playwright C# — Basic Usage
C# / Playwright
C# 
// Tag selector
await page.Locator("button").ClickAsync();

// Class selector
await page.Locator(".submit-btn").ClickAsync();

// ID selector
await page.Locator("#username").FillAsync("testuser");

// Tag + class combination
await page.Locator("input.form-control").FillAsync("value");

// Multiple classes
var el = page.Locator(".btn.btn-primary.active");
await el.ClickAsync();

Combinators
Describe relationships between elements in the DOM tree
Combinator Reference
Structure
A B
Descendant — B anywhere inside A (any depth).
A > B
Child — B that is a direct child of A only.
A + B
Adjacent sibling — B immediately after A (same parent).
A ~ B
General sibling — all B elements after A (same parent).
A, B
Group — selects both A and B (multiple selectors).
Playwright C# — Combinators
C# / Playwright
C# 
// Descendant: input anywhere inside .login-form
await page.Locator(".login-form input").FillAsync("test");

// Direct child: li that is direct child of ul
var items = page.Locator("ul.menu > li");
Assert.AreEqual(5, await items.CountAsync());

// Adjacent sibling: label immediately after input
var lbl = page.Locator("input#email + label");

// General sibling: all p after h2
var paras = page.Locator("h2 ~ p");

// Group: select buttons AND links
var all = page.Locator("button, a.nav-link");
Assert.Greater(await all.CountAsync(), 0);

Attribute Selectors
Target elements by their HTML attributes and attribute values
Attribute Selector Reference
Advanced
[attr]
Element has the attribute (regardless of value).
[attr="val"]
Attribute exactly equals "val".
[attr~="val"]
Attribute is a space-separated list containing "val".
[attr|="val"]
Attribute equals "val" or starts with "val-" (language codes).
[attr^="val"]
Attribute value starts with "val".
[attr$="val"]
Attribute value ends with "val".
[attr*="val"]
Attribute value contains "val" anywhere.
[attr="val" i]
Case-insensitive match (append i flag).
[attr="val" s]
Case-sensitive match (append s flag).
Playwright C# — Attributes
C# / Playwright
C# 
// Has data-testid attribute
await page.Locator("[data-testid]").ClickAsync();

// Exact attribute value
await page.Locator("[data-testid='submit-btn']").ClickAsync();

// Input type (exact)
await page.Locator("input[type='email']").FillAsync("user@test.com");

// href starts with https
var extLinks = page.Locator("a[href^='https']");

// href ends with .pdf
var pdfs = page.Locator("a[href$='.pdf']");

// src contains "thumbnail"
var thumbs = page.Locator("img[src*='thumbnail']");

// Case-insensitive type match
var inputs = page.Locator("input[type='submit' i]");

// Chain: disabled input of type text
var disabled = page.Locator("input[type='text'][disabled]");
await Expect(disabled).ToBeDisabledAsync();

// Checked checkbox
var checked = page.Locator("input[type='checkbox']:checked");

Playwright C# — nth Patterns
C# / Playwright
C# 
// 3rd table row
var row3 = page.Locator("table tr:nth-child(3)");

// Every other row (zebra stripe validation)
var even = page.Locator("tr:nth-child(even)");

// First 3 items in list
var first3 = page.Locator("li:nth-child(-n+3)");
Assert.AreEqual(3, await first3.CountAsync());

// Playwright's .Nth() — zero-based index
var second = page.Locator(".list-item").Nth(1); // 2nd item
var first  = page.Locator(".list-item").First;
var last   = page.Locator(".list-item").Last;

// 2nd paragraph inside article
var p2 = page.Locator("article p:nth-of-type(2)");
var txt = await p2.TextContentAsync();
ℹ Playwright's .Nth(n) uses 0-based indexing, while CSS :nth-child(n) is 1-based. Use .First and .Last for convenience.

Playwright C# — Pseudo-element Workarounds
C# / Playwright
⚠ Playwright cannot directly interact with pseudo-elements (::before, ::after) since they are not real DOM nodes. Use JavaScript evaluation instead.
C# 
// Get computed style of ::before content
var content = await page.EvaluateAsync<string>(@"
    window.getComputedStyle(
        document.querySelector('.icon'), '::before'
    ).content");

// Get ::after color
var color = await page.EvaluateAsync<string>(@"
    window.getComputedStyle(
        document.querySelector('.badge'), '::after'
    ).backgroundColor");

// Check placeholder text via attribute
var ph = page.Locator("input[placeholder='Search...']");
await Expect(ph).ToBeVisibleAsync();

// :placeholder-shown (field still has placeholder visible)
var empty = page.Locator("input:placeholder-shown");

Playwright extends CSS selectors with powerful built-in locator strategies
Playwright Locator API Reference
C# / Playwright
C# — Playwright Locator Strategies 
// ── ROLE LOCATORS (most recommended) ────────────────────────
await page.GetByRole(AriaRole.Button, new() { Name = "Submit" }).ClickAsync();
await page.GetByRole(AriaRole.Textbox, new() { Name = "Email" }).FillAsync("x@x.com");
await page.GetByRole(AriaRole.Link, new() { Name = "Home" }).ClickAsync();
await page.GetByRole(AriaRole.Checkbox).CheckAsync();
await page.GetByRole(AriaRole.Combobox).SelectOptionAsync("Option 1");

// ── TEXT LOCATORS ────────────────────────────────────────────
await page.GetByText("Welcome back").IsVisibleAsync();
await page.GetByText("Submit", new() { Exact = true }).ClickAsync();

// ── LABEL LOCATORS ───────────────────────────────────────────
await page.GetByLabel("Password").FillAsync("s3cret");
await page.GetByLabel("Remember me").CheckAsync();

// ── PLACEHOLDER ──────────────────────────────────────────────
await page.GetByPlaceholder("Search products...").FillAsync("shoes");

// ── ALT TEXT (images) ────────────────────────────────────────
await page.GetByAltText("Company logo").IsVisibleAsync();

// ── TITLE ATTRIBUTE ──────────────────────────────────────────
await page.GetByTitle("Close dialog").ClickAsync();

// ── TEST ID ──────────────────────────────────────────────────
await page.GetByTestId("login-button").ClickAsync();
// Configure custom test ID: playwright.testIdAttribute = "data-cy"

// ── FILTER ON LOCATORS ───────────────────────────────────────
var rows = page.Locator("tr").Filter(new() { HasText = "Pending" });
var cards = page.Locator(".card").Filter(new() { Has = page.Locator("button.active") });

// ── CHAIN LOCATORS ───────────────────────────────────────────
var row = page.Locator("table tbody tr").Nth(0);
var cell = row.Locator("td:nth-child(2)");
var text = await cell.TextContentAsync();

Playwright C# — Form Interactions
C# / Playwright
C# 
// Text input
await page.Locator("input[type='text']").FillAsync("John");

// Email field
await page.Locator("input[type='email']").FillAsync("john@test.com");

// Password
await page.Locator("input[type='password']").FillAsync("P@ssword1");

// Checkbox — only click if not already checked
var cb = page.Locator("input[type='checkbox']#terms");
if (!await cb.IsCheckedAsync())
    await cb.CheckAsync();

// Radio button
await page.Locator("input[type='radio'][value='monthly']").CheckAsync();

// Select dropdown by value / label / index
await page.Locator("select#country").SelectOptionAsync("US");
await page.Locator("select#country")
          .SelectOptionAsync(new SelectOptionValue { Label = "United States" });

// File upload
await page.Locator("input[type='file']")
          .SetInputFilesAsync("./files/test.pdf");

// Textarea
await page.Locator("textarea#message").FillAsync("Hello world");

// Disabled field check
var field = page.Locator("input:disabled");
await Expect(field).ToBeDisabledAsync();

// Required fields
var required = page.Locator("input:required");
Assert.Greater(await required.CountAsync(), 0);

Common Test Patterns
Real-world selector patterns for typical Playwright test scenarios
Real-World Playwright Selector Patterns
C# / Playwright
C# — Navigation & Menus 
// Active navigation item
var activeNav = page.Locator("nav a.active, nav a[aria-current='page']");

// Dropdown menu item
await page.Locator(".dropdown-menu > li > a").Nth(0).ClickAsync();

// Breadcrumb last item
var crumb = page.Locator(".breadcrumb li:last-child");
C# — Tables & Lists 
// Table cell by column position in specific row
var cell = page.Locator("table tbody tr:nth-child(2) td:nth-child(3)");

// Table row containing specific text
var row = page.Locator("tr").Filter(new() { HasText = "Invoice #1024" });

// Table header cells
var headers = page.Locator("table thead th");
var headerTexts = await headers.AllTextContentsAsync();

// Action button inside a specific table row
await row.Locator("button[data-action='delete']").ClickAsync();

// Unordered list items
var items = page.Locator("ul.results > li");
Assert.AreEqual(10, await items.CountAsync());
C# — Modals & Dialogs 
// Modal with specific role
var modal = page.Locator("[role='dialog']");
await Expect(modal).ToBeVisibleAsync();

// Close button inside modal
await modal.Locator("button[aria-label='Close'], button.close").ClickAsync();

// Confirm button in modal footer
await page.Locator(".modal-footer button[type='submit']").ClickAsync();

// Alert/toast messages
var alert = page.Locator("[role='alert'], .toast, .notification");
await Expect(alert).ToContainTextAsync("Success");
C# — Loading & Dynamic States 
// Wait for element NOT to be visible (loading spinner)
await Expect(page.Locator(".spinner, [data-loading='true']"))
      .ToBeHiddenAsync();

// Element with aria-busy false (done loading)
await Expect(page.Locator("[aria-busy='false']"))
      .ToBeVisibleAsync();

// Skeleton screen gone
await Expect(page.Locator(".skeleton")).ToHaveCountAsync(0);

// Error state
var err = page.Locator(".input-group.has-error input, input[aria-invalid='true']");
await Expect(err).ToBeVisibleAsync();

Tips & Best Practices
Selector strategy recommendations for robust, maintainable Playwright tests
Selector Priority (Best → Worst)
Strategy
GetByRole
Best. Accessible, semantic, resilient to style changes.
GetByLabel
Great. Tied to form accessibility, very stable.
GetByTestId
Great. Set data-testid explicitly for automation.
GetByText
Good. Breaks if copy changes, use Exact=true.
[data-*]
Good. Custom data attributes. Stable if maintained.
#id .class
Okay. Fragile if UI is refactored or classes change.
div > span:nth-child(3)
Avoid. Extremely brittle, breaks with DOM changes.
XPath
Avoid. Hard to read/maintain; CSS almost always better.
Scoping & Chaining
Patterns
C# — Scope locators to reduce ambiguity 
// Scope inside a component
var sidebar = page.Locator("aside.sidebar");
var link = sidebar.GetByRole(AriaRole.Link, new() { Name = "Settings" });

// Filter by child element
var activeCard = page
    .Locator(".card")
    .Filter(new() {
        Has = page.Locator(".badge.active")
    });

// Filter by text content
var draftItems = page
    .Locator(".document-row")
    .Filter(new() { HasText = "Draft" });

// Combine filters
var target = page
    .Locator("li")
    .Filter(new() { HasText = "Pro Plan" })
    .Filter(new() {
        Has = page.Locator("[data-active='true']")
    });
Quick Escape Selector Characters
Escaping
⚠ Special characters in selectors must be escaped with a backslash \ if used literally inside identifiers.
C# — Escaping special characters 
// ID with dots (e.g. id="my.id")
var el = page.Locator("#my\\.id");

// Class with colon
var el2 = page.Locator(".tw\\:text-red-500");

// Brackets, colons, slashes in Tailwind classes
var tw = page.Locator("[class*='text-red']"); // safer

// Use attribute selector as fallback for tricky IDs
var el3 = page.Locator("[id='my.id']"); // no escaping needed

✓
Use data-testid attributes — Add data-testid to key elements in your app. They never change with styling/refactors and communicate test intent clearly to developers.
ℹ
Prefer .Filter() over complex selectors — page.Locator(".card").Filter(new() { HasText = "Active" }) is more readable and maintainable than deeply nested CSS selectors.
⚠
Avoid position-based selectors — :nth-child(3) breaks when the UI adds/reorders items. Use text or attribute matching to target specific elements instead.
✓
Use Playwright's built-in assertions — Expect(locator).ToBeVisibleAsync() auto-waits and retries. Never use IsVisibleAsync() directly in assertions without waiting.
