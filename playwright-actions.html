fill()
Clear and type into an input field instantly
type()
Type text character by character, triggering key events
press()
Press a specific key e.g. Enter, Tab, Escape
keyboard.down() / .up()
Hold or release a specific keyboard key
keyboard.insertText()
Insert text without firing individual key events
clear()
Clear the current value of an input field

Uncheck a checkbox

Select option(s) from a <select> dropdown
setInputFiles()
Upload files via a file input element
focus()
Focus on a specific element
blur()
Remove focus (blur) from an element

goto()
Navigate the page to a specified URL
goBack() / goForward()
Navigate browser history back or forward
reload()

waitForNavigation()

waitForTimeout()
Wait for a fixed duration in milliseconds

Wait until a JavaScript function returns truthy

Run JS in browser context and return a serializable value

addStyleTag()

Switch to or interact with elements inside iframes
context.newPage()
Open a new browser tab in the current context

Bring a specific tab to the foreground/focus
context.pages()
List all open pages and tabs in the context
page.close()
Close a tab or page

Network & Interception 6 actions
route()
Intercept and modify or mock outgoing network requests
unroute()
Remove a previously registered network route handler
context.setExtraHTTPHeaders()
Add custom HTTP headers to all outgoing requests
page.setOffline()
Simulate offline / no network connection mode
request.fulfill()
Respond to an intercepted request with custom data
request.abort() / .continue()
Abort or pass through an intercepted request

context.cookies()
Retrieve all current cookies in the context
context.addCookies()
Set or inject cookies into the browser context
context.clearCookies()
Clear all cookies from the current context
context.storageState()
Save or restore full auth state (cookies + localStorage)
evaluate(() => localStorage...)
Read/write localStorage via JS evaluation
