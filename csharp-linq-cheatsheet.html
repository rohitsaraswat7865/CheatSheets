Syntax Basics

Query syntax vs Method (fluent) syntax — two ways to write the same query

What is LINQ? LINQ (Language-Integrated Query) provides a unified model for querying any data source (arrays, lists, XML, databases, APIs) using C# language syntax. Add using System.Linq; to use it.

Query Syntax vs Method Syntax

Side-by-side
Query Syntax (SQL-like)
// Must end with select or group
var result = from n in numbers
             where n > 5
             orderby n descending
             select n * 2;
Method (Fluent) Syntax
// Extension methods on IEnumerable<T>
var result = numbers
    .Where(n => n > 5)
    .OrderByDescending(n => n)
    .Select(n => n * 2);

Deferred vs Immediate Execution

Important
Most LINQ operators use deferred execution — the query runs when iterated, not when defined.
var query = list.Where(x => x > 3); // not executed yet
foreach (var item in query) { } // executed NOW

// Force immediate execution:
var snapshot = query.ToList();  // immediately
var arr      = query.ToArray(); // immediately
var count    = query.Count();   // immediately

Lambda Expression Anatomy

Syntax
Lambdas are the backbone of LINQ method syntax.
// (parameters) => expression
x => x > 5                    // single param
(x, y) => x + y               // multi param
(int x) => x * 2              // typed param
x => { return x * 2; }        // block body

// Using in LINQ
.Where(p => p.Age > 18)
.Select(p => new { p.Name, p.Age })
⚠️ Multiple Enumeration: Calling a deferred LINQ query multiple times re-executes it each time. Call .ToList() or .ToArray() to cache results and avoid repeated work.

Filtering

Restrict elements based on conditions

Where

Filter
Returns elements that satisfy a predicate. The most common LINQ operator.
var adults = people.Where(p => p.Age >= 18);

// Multiple conditions
var result = people.Where(p => p.Age >= 18
                         && p.Country == "UK");

// With index overload
var everyOther = items.Where((x, i) => i % 2 == 0);

OfType<T>

Filter
Filters elements by type, returning only those that are (or cast to) the specified type.
IEnumerable<object> mixed = new object[]
    { 1, "hello", 3.14, "world", 42 };

var strings = mixed.OfType<string>();
// → "hello", "world"

var ints    = mixed.OfType<int>();
// → 1, 42  (3.14 excluded — it's a double)
📐

Projection

Transform elements into new shapes

Select

Project
Maps each element to a new form — shapes the output data.
// Simple value projection
var names = people.Select(p => p.Name);

// Anonymous type projection
var dtos = people.Select(p => new
{
    p.Name,
    AgeGroup = p.Age < 18 ? "Minor" : "Adult"
});

// With index
var indexed = items.Select((x, i) => new { x, i });

SelectMany

Flatten
Flattens nested collections — "map then flatten". Equivalent to flatMap in other languages.
// Flatten list of lists
var orders = customers
    .SelectMany(c => c.Orders);

// Access parent + child
var pairs = customers
    .SelectMany(c => c.Orders,
        (c, o) => new { c.Name, o.Total });

// Flatten strings to chars
var chars = new[] { "ab", "cd" }
    .SelectMany(s => s); // → 'a','b','c','d'

Zip

Combine
Merges two (or three) sequences element-by-element using a result selector.
var names  = new[] { "Alice", "Bob" };
var scores = new[] { 95, 87 };

// With selector
var result = names.Zip(scores,
    (n, s) => $"{n}: {s}");
// → "Alice: 95", "Bob: 87"

// .NET 5+: returns tuples
var tuples = names.Zip(scores);
// → (Alice, 95), (Bob, 87)

Cast<T>

Cast
Casts each element to a type. Throws if cast fails (unlike OfType).
ArrayList legacy = new ArrayList { 1, 2, 3 };

var ints = legacy.Cast<int>();
// → 1, 2, 3 as IEnumerable<int>

// vs OfType — silently skips non-matching
var safe = legacy.OfType<int>();
↕️

Ordering

Sort sequences ascending, descending, or by multiple keys

OrderBy / OrderByDescending

Sort 
// Primary sort ascending
var sorted = people.OrderBy(p => p.LastName);

// Primary sort descending
var desc = people.OrderByDescending(p => p.Age);

// Multi-key sort
var multi = people
    .OrderBy(p => p.LastName)
    .ThenBy(p => p.FirstName)
    .ThenByDescending(p => p.Age);

Reverse

Sort
Reverses the order of a sequence. Note: List<T>.Reverse() is in-place — .Reverse() from LINQ returns a new sequence.
var nums = new[] { 1, 2, 3, 4, 5 };
var rev  = nums.Reverse(); // → 5,4,3,2,1

// ⚠️ List<T>.Reverse() is in-place (void)
List<int> myList = new() { 1, 2, 3 };
myList.Reverse();         // modifies myList

// LINQ version (non-destructive):
var safe = myList.AsEnumerable().Reverse();

Order / OrderDescending (.NET 7+)

Sort
Shorthand for sorting elements that are themselves comparable (no key selector needed).
var nums    = new[] { 3, 1, 4, 1, 5 };
var sorted  = nums.Order();
// → 1, 1, 3, 4, 5

var words   = new[] { "banana", "apple", "cherry" };
var sorted2 = words.OrderDescending();
// → cherry, banana, apple

Custom IComparer

Sort 
// Case-insensitive string sort
var result = words.OrderBy(
    w => w,
    StringComparer.OrdinalIgnoreCase);

// Null-safe natural sort pattern
var sorted = items
    .OrderBy(x => x.Value == null)
    .ThenBy(x => x.Value);
∑

Aggregation

Reduce sequences to a single value

Count()
Number of elements (optionally matching a predicate)
→ int
LongCount()
Count for very large sequences
→ long
Sum()
Sum of numeric values (int, double, decimal…)
→ numeric
Average()
Arithmetic mean. Returns double/decimal
→ double
Min() / Max()
Minimum or maximum value
→ T
MinBy() / MaxBy()
.NET 6+ — returns the element with min/max key
→ T
Aggregate()
Custom fold/reduce with a seed and accumulator function
→ TAccumulate

Common Aggregates

Aggregate 
var orders = db.Orders;

int     count   = orders.Count();
int     above   = orders.Count(o => o.Total > 100);
decimal total   = orders.Sum(o => o.Total);
double  avg     = orders.Average(o => o.Total);
decimal max     = orders.Max(o => o.Total);
decimal min     = orders.Min(o => o.Total);
Order   biggest = orders.MaxBy(o => o.Total);

Aggregate (custom reduce)

Aggregate 
var nums = new[] { 1, 2, 3, 4, 5 };

// Product of all numbers
int product = nums.Aggregate((acc, x) => acc * x);
// → 120

// With seed value
int sum10 = nums.Aggregate(10, (acc, x) => acc + x);
// → 25 (10 + 1+2+3+4+5)

// With seed + result selector
string csv = nums.Aggregate("",
    (a, x) => a + "," + x,
    a => a.TrimStart(',')); // → "1,2,3,4,5"
📦

Grouping

Partition sequences into groups by a key

GroupBy

Group
Returns IEnumerable<IGrouping<TKey, TElement>> — each group has a .Key and is iterable.
// Group people by country
var byCountry = people.GroupBy(p => p.Country);

foreach (var group in byCountry)
{
    Console.WriteLine(group.Key); // country name
    foreach (var p in group)
        Console.WriteLine(p.Name);
}

// With element selector
var namesByCountry = people.GroupBy(
    p => p.Country,      // key selector
    p => p.Name);         // element selector

GroupBy with aggregation

Group 
// Count, sum within groups
var stats = people
    .GroupBy(p => p.Department)
    .Select(g => new
    {
        Dept    = g.Key,
        Count   = g.Count(),
        AvgAge  = g.Average(p => p.Age),
        MaxSal  = g.Max(p => p.Salary)
    });

// Query syntax equivalent
var stats2 = from p in people
             group p by p.Department into g
             select new { Dept = g.Key, Count = g.Count() };

ToLookup

Group
Like GroupBy but executes immediately and returns a random-access ILookup<TKey, T>.
// Builds lookup once (eager)
ILookup<string, Person> lookup =
    people.ToLookup(p => p.Country);

// Random access by key
var uk  = lookup["UK"];
var usa = lookup["USA"];

// Missing key returns empty (no exception)
var none = lookup["Mars"]; // empty, no throw

Multi-key grouping

Group 
// Group by composite (anonymous type) key
var grouped = orders.GroupBy(o => new
{
    o.Year,
    o.Category
});

foreach (var g in grouped)
{
    Console.WriteLine($"{g.Key.Year}/{g.Key.Category}");
}
🔗

Joining

Correlate elements from two sequences

Join (inner join)

Join
Returns matches from both sequences on a key. Unmatched elements are excluded.
var result = orders.Join(
    customers,              // inner sequence
    o => o.CustomerId,      // outer key
    c => c.Id,              // inner key
    (o, c) => new           // result
    {
        c.Name,
        o.Total,
        o.Date
    });

// Query syntax
var q = from o in orders
        join c in customers
          on o.CustomerId equals c.Id
        select new { c.Name, o.Total };

GroupJoin (left join)

Join
Like a left outer join — keeps all outer elements, attaches matching inner elements as a sub-collection.
var result = customers.GroupJoin(
    orders,
    c => c.Id,
    o => o.CustomerId,
    (c, orderGroup) => new
    {
        c.Name,
        OrderCount = orderGroup.Count(),
        Total      = orderGroup.Sum(o => o.Amount)
    });

// Customers with zero orders still appear!

Left Outer Join (LINQ pattern)

Join 
var leftJoin = customers
    .GroupJoin(orders,
        c => c.Id, o => o.CustId,
        (c, og) => new { c, og })
    .SelectMany(
        x => x.og.DefaultIfEmpty(),
        (x, o) => new
        {
            x.c.Name,
            OrderTotal = o?.Total ?? 0
        });

Cross Join

Join
Cartesian product — every combination of elements from both sequences.
var colors = new[] { "Red", "Blue" };
var sizes  = new[] { "S", "M", "L" };

var combos = colors.SelectMany(
    _ => sizes,
    (c, s) => $"{c} {s}");
// → Red S, Red M, Red L, Blue S…

// Query syntax
var q = from c in colors
        from s in sizes
        select $"{c} {s}";

Set Operations

Distinct, union, intersect, except

Distinct / DistinctBy

Set
var nums = new[] {1,2,2,3,3};
var d = nums.Distinct();
// → 1, 2, 3

// .NET 6+: distinct by key
var unique = people
    .DistinctBy(p => p.Email);

Union / UnionBy

Set
var a = new[] { 1, 2, 3 };
var b = new[] { 2, 3, 4 };
var u = a.Union(b);
// → 1, 2, 3, 4

// .NET 6+: union by key
var all = list1.UnionBy(list2,
    p => p.Id);

Intersect / IntersectBy

Set
var a = new[] { 1, 2, 3 };
var b = new[] { 2, 3, 4 };
var i = a.Intersect(b);
// → 2, 3

// .NET 6+: intersect by key
var common = list1
    .IntersectBy(list2.Select(x => x.Id),
        x => x.Id);

Except / ExceptBy

Set
var a = new[] { 1, 2, 3 };
var b = new[] { 2, 3 };
var e = a.Except(b);
// → 1 (a minus b)

// .NET 6+: except by key
var notIn2 = list1
    .ExceptBy(list2.Select(x => x.Id),
        x => x.Id);

SequenceEqual

Set
var a = new[] { 1, 2, 3 };
var b = new[] { 1, 2, 3 };
bool eq = a.SequenceEqual(b);
// → true

// With custom comparer
bool eq2 = strA.SequenceEqual(strB,
    StringComparer.OrdinalIgnoreCase);

Concat

Combine
var a = new[] { 1, 2 };
var b = new[] { 3, 4 };
var c = a.Concat(b);
// → 1, 2, 3, 4 (duplicates kept)

// Append / Prepend single element
var d = a.Append(99);  // → 1,2,99
var e = a.Prepend(0); // → 0,1,2
①

Element Operators

Retrieve a single element from a sequence

Element Operator Reference

Method Description If empty / not found
First() First element (or matching predicate) throws InvalidOperationException
FirstOrDefault() First element or default (null/0) returns default(T)
Last() Last element (or matching predicate) throws InvalidOperationException
LastOrDefault() Last element or default returns default(T)
Single() Exactly one element (error if 0 or 2+) throws on 0 or multiple
SingleOrDefault() One or zero elements returns default; throws if multiple
ElementAt(n) Element at zero-based index throws ArgumentOutOfRangeException
ElementAtOrDefault(n) Element at index or default returns default(T)
DefaultIfEmpty() Sequence with single default if empty returns [default(T)]

Safe element access patterns

Element 
// With fallback default (.NET 6+)
var first = list.FirstOrDefault(x => x > 5, -1);
// returns -1 if nothing matches

// Defensive coding
Person? found = people
    .FirstOrDefault(p => p.Id == id);

if (found is null)
    throw new KeyNotFoundException($"Id {id} not found");

Index from end (.NET 6+)

Element 
var items = new[] { 10, 20, 30, 40, 50 };

// .NET 6+: Index from end with ^
var last       = items.ElementAt(^1); // → 50
var secondLast = items.ElementAt(^2); // → 40

// DefaultIfEmpty example
var safe = emptyList
    .DefaultIfEmpty(0)
    .Sum(); // → 0 instead of exception

Quantifiers

Test conditions across sequences

Any

Bool
Returns true if any element matches (or if sequence is non-empty with no predicate).
bool hasAdults = people
    .Any(p => p.Age >= 18);

bool notEmpty = list.Any();
// faster than Count() > 0

All

Bool
Returns true only if every element matches. Returns true for empty sequences.
bool allAdults = people
    .All(p => p.Age >= 18);

// Empty sequence returns true:
bool trivially = Enumerable
    .Empty<int>().All(x => x > 0);
// → true (vacuously true)

Contains

Bool
Tests if a specific value is in the sequence.
bool has5 = numbers.Contains(5);

// With custom comparer
bool found = names.Contains(
    "alice",
    StringComparer.OrdinalIgnoreCase);
// → true for "Alice" or "ALICE"
✂️

Partitioning

Skip and take — slicing sequences and pagination

Take / Skip / Range

Partition 
var page1   = items.Take(10);          // first 10
var page2   = items.Skip(10).Take(10); // next 10
var last5   = items.TakeLast(5);       // .NET 2+
var drop5   = items.SkipLast(5);       // .NET 2+

// .NET 6+: Range index
var slice   = items.Take(2..8);         // index 2-7
var last3   = items.Take(^3..);         // last 3

TakeWhile / SkipWhile

Partition
Predicate-based partitioning — stops at the first non-matching element.
var nums = new[] { 1, 3, 5, 6, 8, 9 };

// Take while odd
var tw = nums.TakeWhile(n => n % 2 != 0);
// → 1, 3, 5 (stops at 6)

// Skip while odd
var sw = nums.SkipWhile(n => n % 2 != 0);
// → 6, 8, 9

Pagination helper pattern

Pattern 
static IQueryable<T> Paginate<T>(
    IQueryable<T> query,
    int page,       // 1-based page number
    int pageSize)   // items per page
{
    return query
        .Skip((page - 1) * pageSize)
        .Take(pageSize);
}

Chunk (.NET 6+)

Partition
Splits a sequence into fixed-size chunks — perfect for batch processing.
var ids = Enumerable.Range(1, 100);

foreach (var batch in ids.Chunk(10))
{
    // each batch is int[] of up to 10 items
    await ProcessBatchAsync(batch);
}
// Perfect for API rate limiting, bulk inserts

Generation Operators

Create sequences from scratch

Enumerable.Range

Generate
// Range(start, count)
var r1 = Enumerable.Range(1, 10);
// → 1..10

var squares = Enumerable
    .Range(1, 5)
    .Select(n => n * n);
// → 1, 4, 9, 16, 25

Enumerable.Repeat

Generate
// Repeat(value, count)
var zeros = Enumerable
    .Repeat(0, 5);
// → 0, 0, 0, 0, 0

var fills = Enumerable
    .Repeat("N/A", 3);// → "N/A" ×3

Enumerable.Empty

Generate
// Zero-element typed sequence
var empty = Enumerable
    .Empty<string>();

// Useful as a safe default
IEnumerable<Order> GetOrders() =>
    _cache ?? Enumerable.Empty<Order>();

Conversion Operators

Convert sequences to collections and dictionaries

ToList / ToArray / ToHashSet

Convert 
List<Person> list    = query.ToList();
Person[]      arr     = query.ToArray();
HashSet<int>  set     = ids.ToHashSet();

// ToHashSet with comparer
HashSet<string> ci = names.ToHashSet(
    StringComparer.OrdinalIgnoreCase);

ToDictionary / ToLookup

Convert 
// Key must be unique or throws
Dictionary<int, Person> byId = people
    .ToDictionary(p => p.Id);

// Key + value selector
Dictionary<int, string> map = people
    .ToDictionary(p => p.Id, p => p.Name);

// Multiple per key → ToLookup
ILookup<string, Person> lkp = people
    .ToLookup(p => p.Country);

AsEnumerable / AsQueryable

Convert
Switch between LINQ to Objects (in-memory) and LINQ to SQL/EF (expression trees).
// Force client-side evaluation
var result = dbContext.Products
    .Where(p => p.Active)     // SQL
    .AsEnumerable()           // switch to memory
    .Where(p => MyComplexFn(p)); // in-memory

// Wrap IEnumerable as IQueryable
var q = list.AsQueryable();

string.Join (LINQ + strings)

Pattern 
var names = people
    .Select(p => p.Name);

string csv  = string.Join(", ", names);
string list = string.Join("\n", names);

// .NET 6+ — chunk into string batches
var batches = ids
    .Chunk(100)
    .Select(b => string.Join(",", b));

Common Patterns & Best Practices

Real-world recipes and performance tips

✅ Performance tips: Use Any() over Count() > 0. Prefer FirstOrDefault() over Where().First(). On EF Core, keep filters before AsEnumerable() to translate to SQL. Avoid ToList() inside loops.

Null-safe LINQ

Pattern 
// Null-safe iteration
var safe = (maybeNull ?? Enumerable.Empty<T>())
    .Where(x => x is not null);

// Filter out nulls (.NET 6+ pattern)
var nonNull = list
    .Where(x => x is not null)
    .Select(x => x!);

Flattening nested data

Pattern 
// Flatten 3 levels deep
var allTags = posts
    .SelectMany(p => p.Tags)
    .Distinct()
    .OrderBy(t => t);

// Flatten with correlation
var flat = categories
    .SelectMany(c => c.Products,
        (c, p) => new { c.CategoryName, p.Name });

Dynamic / conditional filtering

Pattern 
IQueryable<Product> q = db.Products;

if (minPrice.HasValue())
    q = q.Where(p => p.Price >= minPrice);

if (!string.IsNullOrEmpty(category))
    q = q.Where(p => p.Category == category);

return await q.ToListAsync();

String search / contains

Pattern 
var term = "alice";

// Case-insensitive search
var found = people.Where(p =>
    p.Name.Contains(term,
        StringComparison.OrdinalIgnoreCase));

// In EF Core (translates to LIKE)
var efSearch = db.People.Where(p =>
    EF.Functions.Like(p.Name, $"%{term}%"));

Batch deduplication

Pattern 
// Deduplicate by composite key
var unique = records
    .GroupBy(r => new { r.Name, r.Date })
    .Select(g => g.First());

// Or with DistinctBy (.NET 6+)
var unique2 = records
    .DistinctBy(r => (r.Name, r.Date));

Async LINQ (EF Core)

Async 
using Microsoft.EntityFrameworkCore;

// Async terminal operators
List<Product> list  = await q.ToListAsync();
int           count = await q.CountAsync();
Product?      first = await q.FirstOrDefaultAsync();
bool          any   = await q.AnyAsync(p => p.Active);

// Async streaming (.NET 6+)
await foreach (var item in q.AsAsyncEnumerable())
    Process(item);
